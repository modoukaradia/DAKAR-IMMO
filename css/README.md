# Dakar Immo

Dakar Immo est un site immobilier moderne permettant de rechercher, vendre et louer des biens immobiliers au Sénégal.

## Fonctionnalités

- Recherche de maisons et appartements
- Affichage des biens populaires
- Page de contact
- Site responsive
- Design moderne

## Technologies utilisées

- HTML5
- CSS3
